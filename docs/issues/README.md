# docs/issues

GitHub 이슈로 올리기 전 초안과 작업분배표를 두는 곳이다. Claude 스킬 `crm-issue-splitter`가 여기에 만든다.

| 파일 | 내용 |
| --- | --- |
| `NN_짧은제목.md` | 이슈 하나 (NN = 착수 순서 두 자리, 예: `01_공통 기반.md`) |
| `작업분배(YYYY-MM-DD).md` | 전체 이슈 목록, 착수 순서, 담당 제안, 계약, 파일 소유표 |

- GitHub에 올린 뒤에는 GitHub 이슈가 기준이다. 번호가 다르면 작업분배표에 대응표를 남긴다.
- 이슈 내용을 고칠 때는 GitHub 이슈를 고치고, 여기 초안은 고치지 않아도 된다.
