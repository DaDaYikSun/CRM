## 구현 범위
- 포함:
  - `grooming/` 화면: 미용 예정 목록 탭(오늘 / 이번 주 월~일), 오늘 · 이번 주 기준과 정렬은 연락 대상 목록과 같음, 보호자 번호는 뒤 4자리 (FR-VIS-002, 화면 설계 SCR-S11-02)
  - 오늘 미용을 기록한 아이는 '미용 완료'로 목록 아래에 남김 (`groomedToday`, API 설계 3장)
  - 오른쪽 선택한 아이: 다음 미용 예정 · 개인 주기, 접종 상태(보기만), 미용 이력, [미용 기록] → S-09 → 다음 미용 예정일
  - 미용 예정 목록 API `GET /api/grooming?tab=today|week&page=` (API 설계 3장 [제안])
  - 미용사에게 보이는 메뉴는 검색 · 미용만 (POL-ACC-011, 화면 설계 SCR-COM-02)
- 제외 (다른 이슈 / v2):
  - 검색 · 상세 · 모달 자체 (#05 · #08 · #07), 서버 역할 검사 장치 (#02)
