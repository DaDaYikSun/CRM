## 다른 이슈와의 연결 (API · 함수)
- 제공 C10 보호자 상세 · 수정

  - `PATCH /api/guardians/{id}` 입력 `{ name?, phone?, subPhone?, preferredContact?, tags? }`
  - `PATCH /api/pets/{id}` 입력 `{ name?, birthDate?, breedId?, coatTypeId?, weightKg? }`

- 부르는 것: C4 `CycleService.recalculatePet`, C3 관리자 검사
