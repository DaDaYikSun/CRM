## 구현 범위
- 포함:
  - 보호자 줄 클릭 → 목록 그대로 두고 오른쪽 패널: 같은 집 아이별 예정 항목, 지난 연락 기록(열 때 불러옴), 선호 연락 방법, 주의 태그, 전체 번호
  - 오늘 이미 연락했으면 '오늘 {직원}이 {시간}에 연락했습니다.' (기록은 가능)
  - 결과 버튼 5개 · 메모(200자, 안내 문구) · 통화한 사람(본인 · 가족) · 연락 방법(전화 · 문자) · 다음 연락 예정일
  - 결과는 예정 항목(아이 × 서비스)마다 하나, 기본값은 같은 결과로 채움
  - 저장 → `contact_log` 행들(같은 `contact_group_id`) + 같은 트랜잭션에서 C14 후속 처리 호출 → 토스트
- 제외 (다른 이슈 / v2):
  - 결과별 후속 처리 규칙 · 전환 (#13), 문자 보내기 (#24), 같은 집 일괄 적용 체크박스 (#29), '처리됨' 줄 (#23), 기록 수정 (#28)

## 다른 이슈와의 연결 (API · 함수)
- 제공 C13 연락 패널 · 결과 저장
  - `GET /api/guardians/{id}/contact-panel` → `{ guardian{ name, phone(전체), preferredContact, tags }, todayContact{ staffName, time }?, pets: [{ petId, name, items: [{ scheduleId, serviceType, vaccineType, dueDate }] }] }`
  - `GET /api/guardians/{id}/contacts?page=` → 지난 연락 기록
  - `POST /api/contacts` 입력 `{ guardianId, method, talkedWith, memo, nextContactDate, items: [{ scheduleId, result }] }` → `{ contactGroupId }`
- 부르는 것: C14 `ContactFollowUpService.apply(contactGroupId)` (#13, 머지 전에는 빈 구현), C3 현재 직원
