# #05 [FR-SRCH-001 · FR-SRCH-002] 통합 검색 (상단 검색창 · 결과 페이지)

## 기획 근거
FR-SRCH-001, FR-SRCH-002 → POL-DATA-002, 정책 4-2(검색 결과 많음 문구), 정책 6장(목록 20개) → TopBar 검색창, S-05
비기능: NFR-PERF-002, NFR-PERF-003, NFR-SEC-003

## 우선순위
P1

## 영역
frontend, backend

## 선행 이슈
#01, #04 (보호자 · 아이 데이터. 테이블은 #01 DDL로 먼저 개발 가능)

## 브랜치
`feat/05-unified-search`

## 구현 범위
- 포함:
  - TopBar 검색창 하나: 번호 뒤 4자리 · 보호자 이름 · 아이 이름, 띄어쓰기 · 하이픈 무시
  - 입력하는 동안 드롭다운 미리보기 (입력 멈춘 뒤 0.5초 안), Enter → S-05 전체 결과
  - 결과마다 보호자 이름 · 번호 뒤 4자리 · 품종 · 나이, 20개씩 페이지
  - 결과 많을 때 안내 문구, 결과 클릭 → 아이 상세(S-07)
- 제외 (다른 이슈 / v2):
  - 초성 검색 · 결과 없음 → 새로 등록 (#22), 무지개다리 회색 표시 (#21)
