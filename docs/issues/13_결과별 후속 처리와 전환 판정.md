## 완료 조건
- [ ] '전화 안 받음'을 저장하면 다음 날 대상에 다시 나온다 (FR-CNT-003 확인 방법)
- [ ] '번호 오류'를 저장하면 대시보드 번호 오류 모음에 나온다 (FR-CNT-003 확인 방법 — 모음 화면은 #20, 여기서는 `phone_status`까지)
- [ ] 계속 안 받으면 2일차까지만 매일 올리고, 2일차에도 안 받으면 문자로 한 번 안내(모의 발송)하고 이번 주기는 끝낸다 (POL-TGT-006). 문구 "이틀 연속 받지 않았습니다. 안내 문자를 보내고 이번 주기 연락을 마칩니다." (정책 4-2)
- [ ] 예약함 · 거절 · 다른 병원 다님은 정책 정의서 2-4장 규칙대로 빠진다 (POL-TGT-007~009)
- [ ] 연락 뒤 예정일 + 14일 안에 그 서비스 방문을 넣으면 그 연락이 '전환'으로 바뀐다. 15일째 방문이면 전환이 아니다 (FR-CNT-004 확인 방법)
- [ ] 방문 전 연락이 여러 번이면 방문 직전 마지막 연락만 전환이다 (POL-MISS-006)
- [ ] 연락한 서비스로 왔을 때만 전환이다. 접종 연락 뒤 미용만 받으면 전환이 아니다 (POL-MISS-007)
- [ ] 문자 발송은 실제로 보내지 않고, 나중에 실제 서비스로 바꿀 수 있게 따로 분리돼 있다 (NFR-EXT-001)

## 테스트 항목
- 정상: 전화 안 받음 1일차 → 2일차 → 문자 · CLOSED, 각 결과 유형 뒤 상태, 전환 14일째 / 15일째, 연락 2번 뒤 방문
