백오피스는 원장과 데스크 실장(관리자 계정)이 쓰는 화면이다. 데스크와 미용사가 매일 쓰는 화면 밖에서 직원 계정, 주기 규칙, 연락 설정을 관리하고 재방문 결과를 본다. 괄호 안은 근거가 된 문제 결정판·후속 안건 ID다.

---

## 1. 권한

| 역할 | 쓰는 화면 | 백오피스 |
| --- | --- | --- |
| 관리자 (원장·데스크 실장) | 모든 화면 | 직원 관리, 규칙 설정, 재방문 통계 |
| 데스크 직원 | 대상 목록, 반려동물 프로필, 연락 기록, 아이 일정 요약 리포트 | 접근 불가 |
| 미용사 | 미용 탭(S-11), 아이 검색, 아이 상세 읽기(미용 이력·접종 상태), 미용 기록 입력. 연락·보호자 전체 번호·대시보드·등록·접종 기록은 403 [팀 결정 T3] | 접근 불가 |

- 모든 직원은 자기 계정으로 로그인하고, 웹 브라우저로 어느 PC에서나 접속한다 (E2).
- 연락 기록에는 기록한 직원과 시간이 자동으로 남는다 (B2).

## 2. 백오피스 기능

| 영역 | 기능 | 하는 일 | 근거 |
| --- | --- | --- | --- |
| 직원 관리 | 직원 계정 | 직원 계정 등록·비활성화, 역할(관리자·데스크·미용사) 지정 | E2 |
| 주기 규칙 | 접종 일정 규칙 표 | 나이 구간별 접종 일정과 심장사상충·구충 예방약 간격을 수정 | C1 |
| 주기 규칙 | 미용 기본 간격 | 털 유형별 기본 간격(단모 10주, 중모 7주, 장모·곱슬 5주)을 수정. 미용 기록이 2회 미만인 아이에게만 쓴다 | C1 |
| 주기 규칙 | 누락 기준 | 개인 예정일이 지나고 며칠이 넘도록 방문이 없으면 누락으로 볼지 설정 (기본 14일) | 기획 |
| 주기 규칙 | 규칙 변경 이력 | 접종 규칙 표, 미용 기본 간격, 누락 기준, 연락 보류 기간을 바꾸면 누가·언제·어떤 값을 무엇으로 바꿨는지 남기고 목록으로 보여줌 | 팀 결정 |
| 연락 설정 | 무지개다리 연락 보류 기간 | 같은 집 다른 아이를 연락 보류로 표시하는 기간 (기본 30일) | H1 |
| 입력 선택지 | 품종·털 유형 목록 | 프로필 입력 때 고르는 품종·털 유형 선택지를 관리 | B1, 후속 D2 |
| 모니터링 | 재방문 통계 | 서비스별 재방문율, 접종 누락률, 연락 결과 유형별 전환율 | 기획 |
| 모니터링 | 연락 방법별 전환율 | 전화·문자 중 어떤 방법이 재방문으로 이어졌는지 | G4 |
| 모니터링 | 번호 오류 보호자 모음 | 연락 결과가 '번호 오류'인 보호자 목록, 번호 마지막 확인 날짜 | A3 |
| 모니터링 | 개선 방향 | 따로 기능을 두지 않고 연락 결과·거절 통계로 대신 | F4, 후속 N1 |

### 2-1. 화면 ID

| ID | 화면 | 담는 기능 | 관련 요구사항 |
| --- | --- | --- | --- |
| B-01 | 직원 관리 | 직원 계정 등록·비활성화, 역할 지정, 비밀번호 초기화 | FR-ADM-001, FR-ADM-007 |
| B-02 | 주기 규칙 | 접종 일정 규칙 표, 미용 기본 간격 | FR-ADM-002, FR-ADM-003 |
| B-03 | 기준값·선택지 | 누락 기준, 무지개다리 연락 보류 기간, 품종·털 유형 목록 | FR-ADM-004, FR-ADM-005 |
| B-04 | 문자 문구·병원 정보 | 접종·미용 안내 문구, 병원 이름·전화번호 | FR-ADM-008 |
| B-05 | 리포트 양식 | 담을 항목, 제목, 지난 이력 기간, 아래 안내 문구 | FR-ADM-009 |
| B-06 | 변경 이력 | 규칙·기준값·문구·양식을 누가·언제·무엇으로 바꿨는지 | FR-ADM-006 |

- B-01~B-06 모두 관리자만 연다. 다른 역할은 권한 없음 안내, 서버는 403 (FR-AUTH-002).

**바꾸지 않는 값:** 연락 결과 유형 5가지(예약함 / 전화 안 받음 / 거절 / 다른 병원 다님 / 번호 오류)와 주의 태그 4가지(연락 선호 시간·연락 원치 않음·문자만·예민함)는 고정이다. 통계를 낼 수 있게 정해진 버튼으로만 기록한다 (B2, B3).

### 미용 주기 계산

1. 미용 기록이 0~1회인 아이: 털 유형별 기본 간격을 쓴다 (단모 10주, 중모 7주, 장모·곱슬 5주, 백오피스에서 수정).
2. 기록이 2회 이상인 아이: 최근 방문 간격(최대 4개)의 중앙값을 그 아이의 주기로 쓴다. 한 번 유독 늦게 온 기록에 주기가 흔들리지 않도록 평균 대신 중앙값을 쓴다.
3. 다음 예정일 = 마지막 미용일 + 그 아이의 주기. 누락 기준(예정일 + 14일)은 그대로다.

**참고:** 유사 프로그램 MoeGo는 직원이 보호자 단위로 정한 주기 + 마지막 방문일로 계산하고, 방문 기록으로 낸 실제 주기는 참고로만 보여준다 ([MoeGo 설명서](https://help.moego.pet/en/articles/11403266-communication-rebook-reminders)). 털 유형별 권장 간격은 단모 8~12주, 중모 6~8주, 장모·곱슬 4~6주다 ([GroomBoard](https://groomboard.com/blog/pet-grooming-client-retention-strategies)).

## 3. 주요 흐름

### 처음 세팅

1. 관리자 계정으로 로그인한다.
2. 직원 계정을 만들고 역할을 지정한다.
3. 접종 일정 규칙 표와 미용 기본 간격을 병원 기준에 맞게 확인·수정한다.
4. 누락 기준(기본 14일)과 연락 보류 기간(기본 30일)을 확인한다.
5. 데스크 직원이 반려동물 프로필 등록을 시작한다.

### 주간 점검

1. 재방문 통계에서 접종 누락률과 서비스별 재방문율을 본다.
2. 연락 결과 유형별·연락 방법별 전환율에서 효과가 낮은 연락을 찾는다.
3. 번호 오류 보호자 목록을 데스크에 넘겨 방문 때 번호를 확인하게 한다.

### 규칙 변경

1. 접종 규칙 표 또는 미용 기본 간격을 수정한다.
2. 저장하면 변경 이력(누가·언제·무엇을)이 남고, 아이들의 다음 예정일이 새 규칙으로 다시 계산된다.
3. 데스크의 오늘·이번 주 대상 목록에 바로 반영된다.

## 4. 예외 처리

| 상황 | 처리 |
| --- | --- |
| 관리자가 아닌 직원이 백오피스 주소로 들어옴 | 메뉴를 보이지 않게 하고, 주소로 들어오면 권한이 없다고 안내 |
| 직원이 퇴사함 | 계정을 지우지 않고 비활성화. 그 직원이 남긴 연락 기록은 그대로 둔다 |
| 규칙 값이 비었거나 0일 | 저장을 막고 입력할 값을 안내 |
| 아직 기록이 없음 (처음 사용) | 통계 자리에 '아직 기록이 없습니다' 표시 |
| 무지개다리가 된 아이 | 연락 대상·누락 목록·모든 통계에서 제외 (H1) |
| 같은 전화번호로 다시 등록 | 경고하고 기존 보호자로 연결. 합치기 기능은 없다 (A5) |

## 5. 백오피스에서 하지 않는 것

- 진료·수납·예약 관리: 기존 차트의 일이다.
- 중복 보호자 합치기 (A5), 실제 문자 발송 설정 (C1, 모의 발송)
- v2로 미룬 것: 노쇼 관리 (C4), 미용 패키지 (D2), 리뷰 분석 (후속 N1), 온보딩 자료 (후속 D3)
